# ResNet 交互式教学网页

基于论文 *Deep Residual Learning for Image Recognition* 制作的中文 React + TypeScript 教学项目。网页以“钢琴排练”为统一类比，通过 10 个教学章节和 11 个交互模块解释退化问题、残差学习、shortcut、网络结构及实验结果。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址即可查看网页。

## 构建检查

```bash
npm run build
```

构建结果输出到 `dist/`。

## 论文来源

- Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun. *Deep Residual Learning for Image Recognition*.
- 论文链接：https://arxiv.org/abs/1512.03385

本项目未复制论文原图，交互图形均由网页代码绘制。
