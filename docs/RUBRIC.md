# 评分标准

本标准满分 100 分，用于统一作品审核和现场考核尺度。最终通过线和等级划分由教师或考核组织者确定。

## 1. 评分构成

| 维度 | 分值 | 主要考查内容 |
| --- | ---: | --- |
| 论文理解 | 20 | 能否准确说明研究问题、核心动机、方法贡献、适用条件和局限 |
| 内容准确性 | 20 | 公式、模型结构、实验数据、结论和引用是否与原论文一致 |
| 教学设计 | 15 | 章节顺序、类比、概念递进和中文讲解是否有助于理解 |
| 交互效果 | 15 | 操作是否对应论文概念，状态变化和反馈是否即时、有效 |
| 页面与工程质量 | 10 | 项目能否运行和构建，桌面端与移动端是否正常，资源路径是否可靠 |
| 人工修改质量 | 15 | 是否发现初版问题并完成至少三项有依据的实质性修改 |
| 现场展示 | 5 | 能否在 5–8 分钟内使用最终教程清楚讲解论文 |
| **合计** | **100** |  |

## 2. 各维度评分参考

### 论文理解（20 分）

- 17–20：问题、方法、贡献和局限形成完整因果链，能回答追问；
- 13–16：主体理解正确，但部分动机、条件或局限解释不充分；
- 8–12：可以复述论文，但方法与实验之间的关系不清楚；
- 0–7：存在根本性误解，无法说明论文解决了什么问题。

### 内容准确性（20 分）

- 17–20：关键事实、公式、数据和结论准确，引用可以追溯；
- 13–16：主体准确，存在少量不影响核心理解的疏漏；
- 8–12：存在多处数字、术语或因果关系错误；
- 0–7：核心方法、公式或结论出现重大错误。

### 教学设计（15 分）

- 13–15：从问题到直觉、交互、公式和结论递进自然；
- 10–12：结构完整，但部分章节跳跃、重复或类比不够贴合；
- 6–9：内容堆叠明显，学习路径不清楚；
- 0–5：基本照搬论文，缺少教学组织。

### 交互效果（15 分）

- 13–15：主要交互直接表达论文机制，操作后有清晰状态变化和反馈；
- 10–12：交互可用，但部分模块与概念联系较弱；
- 6–9：以装饰性动画或被动展示为主；
- 0–5：主要交互失效、误导或无法操作。

### 页面与工程质量（10 分）

- 9–10：安装、运行、构建均通过，桌面端和移动端无明显问题；
- 7–8：主体可用，存在少量布局或资源问题；
- 4–6：需要额外手工处理才能运行，或移动端问题明显；
- 0–3：无法正常运行、构建或完成主要浏览流程。

### 人工修改质量（15 分）

- 13–15：至少三项高质量修改，覆盖两个及以上类别，证据完整；
- 10–12：达到三项要求，修改有效但影响范围或说明深度一般；
- 6–9：有修改，但部分不够实质或缺少原文依据；
- 0–5：少于三项实质性修改，或基本直接提交初版。

### 现场展示（5 分）

- 5：时间控制合理，能利用交互解释关键机制并回答问题；
- 3–4：基本讲清论文，存在节奏或页面使用问题；
- 1–2：主要复述页面，论文逻辑和交互展示不足；
- 0：未完成展示或无法说明作品内容。

## 3. 实质性修改判定

有效修改包括：

- 纠正论文事实、公式、实验数字或结论错误；
- 重写难以理解、过度简化或容易误导的讲解；
- 调整章节顺序、概念递进或类比映射；
- 修复交互逻辑、状态同步、即时反馈或无障碍问题；
- 补充能够帮助理解论文机制的技术视图或实验对比；
- 修复桌面端、移动端布局和关键资源问题。

以下通常不计入：

- 仅修改文件名、标点或错别字；
- 仅更换颜色、阴影、圆角或无关装饰；
- 仅更新依赖、格式化代码或整理目录；
- 没有说明问题、原因和结果的笼统“优化”；
- Agent 自动完成、本人未核查且无法解释的修改。

至少三项修改应覆盖两个及以上类别。每项修改必须能够在原论文、初版问题或实际测试结果中找到依据。

## 4. 重大问题处理

出现以下情况时，应先退回修改，不进入最终评分：

- 项目无法安装、启动或完成基本浏览；
- 核心论文、作者或链接与作品不一致；
- 少于三项实质性修改；
- 提交密钥、个人隐私或无权使用的素材到仓库；
- 作品包含大面积无法解释的内容或明显未完成部分。
