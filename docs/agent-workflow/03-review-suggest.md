# 功能三：给出人工修改建议

**定位：本功能只产出「修改建议」，不要求 Agent 实际修改项目代码。**

Agent 可根据原论文和实际测试，向参与者列出候选问题，每项包含：

- 初版问题和位置；
- 论文原文、公式、实验数据或测试结果依据；
- 建议修改内容；
- 修改原因和预期效果；
- 所属类别。

> **本功能不强制 Agent 在此处动手改代码。** 因为后续的实质性修改，由参与者拿到建议后，可能单独再开一个对话，甚至在其他 Agent 或直接编辑 `html_output/<slug>_<source>/` 源码完成，跨多次会话。

完成后生成一页以内的修改说明草稿，每项写明问题、修改内容、原因和验证结果（「验证结果」可标注为「待参与者在后续编辑中落实，仅供参考」）。该文件保存在仓库外，不放入 `html_output/`。
